Método y límites de interpretación
  1. El cociente instrumental conserva las señales A y B, los blancos compatibles y la configuración de adquisición.
  2. La corrección de fondo no elimina artefactos producidos por un denominador bajo o ruidoso.
  3. La curva se invierte únicamente dentro del intervalo calibrado y sin extrapolación automática.
  4. Las lecturas internas de una captura estiman repetibilidad inmediata; las réplicas exigen ensayos completos.
