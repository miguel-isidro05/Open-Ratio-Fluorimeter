# Software

## GUI V2.

[`Arduino_Mega_AS7341_GUI/v2.0/`](Arduino_Mega_AS7341_GUI/v2.0/) es la aplicación vigente para el montaje de demostración. Muestra la telemetría multicanal, controla la adquisición y el PWM, refleja la pantalla del instrumento y registra experimentos. La carpeta `v1.0` se conserva como historial de la primera interfaz funcional.

## GUI V1

[`IO_Rodeo_TSL2591_GUI/v1.0/`](IO_Rodeo_TSL2591_GUI/v1.0/) es la primera interfaz PyQt para observar y controlar la copia TSL del firmware del PyBadge mediante USB CDC.
